# 费曼学习工作室

一个由学习者主导、Codex 协助、GitHub 保存学习轨迹的学习系统。当前为 v0.2.1 本地草案：基于 Nacos 试跑，为费曼解释闭环增加依据检查；更新后的行为尚待再次试跑验证。

## 使用

克隆本仓库，在仓库目录启动支持项目 Skill 的 Codex。三个 Skill 位于 `.agents/skills/`；重新打开会话后检查 Skill 列表是否出现它们。项目发现能力取决于使用的 Codex 版本与客户端。

- `$material-distill 帮我提炼这篇文章：<链接>`
- `$understanding-check 我对这个主题的解释是……请检验我。`
- `$learning-archive 将本次学习归档到 topics/<主题>/。`
- `$understanding-check 复测 topics/<主题>/，先不要展示答案。`

也可以用自然语言描述需求。流程可从任意一步进入，按需要返回材料、解释或实验环节。

要从 GitHub 单独安装 Skill，可在支持 Skill 安装器的 Codex 中提供仓库 URL 和 `.agents/skills/<名称>` 路径，请安装器安装。实际命令以当前客户端安装器为准。每个 Skill 自带核心规则，单独安装也可工作；学习文件写入当前指定的学习仓库，不写入 Skill 安装目录。安装不会同步笔记。

## 工作流

提炼核心 → 向新手解释（自主抽象、跨领域关联） → 一个关键缺口 → 定点补学 → 自己重讲 → 理解图 → 按需归档或复测。

重点训练抽象和关联能力。关联可来自其他学科、事物与生活经验；由你先提出，Codex 检查对应结构、依据及边界。一次费曼解释闭环后默认用 Mermaid 表达你形成的理解，标明不确定连接和 AI 补充，支持看图重做。没有跨领域联想时不强行添加。

材料提炼默认覆盖正文全部主要章节，讲清核心概念关系并标明补充与缺失；完成后等待你加工，不自动进入考问。验证题先检查所需前提是否已经提供；超出已学范围时先补材料或标为探索题，不据此判断理解不足。验证阶段每轮默认聚焦一个问题。你随时可以要求直接讲解、增加提示、暂停、归档或重做。

你的默认偏好是抓住核心：完整检查来源后筛选重点，必要时提供简短覆盖索引，不逐项教学或要求全面掌握。

## v0.2.1：先确认问题有依据

问问题、肯定或纠正前，检查具体前提是否有来源、是否已讲过。AI 说过的假设不能自动变成事实，类比情节不能反推产品机制。原文没讲的实现，先查证或作为可选探索；不当成用户应知内容。

发现超纲就停止该问题链，撤回无依据评价，记录材料不足或 AI 越界。保留用户已有的抽象成果，不强制重讲未知机制，也不因此降低掌握状态。参见 [AgentSpec 试跑案例](docs/v0.2.1-cases.md)。

## v0.2 的关键变化

之前常在“用户类比 → AI 纠正 → 画图”结束。现在出现重要补充后，会把解释权交回给你，请你向一个新手重新讲清关键关系。对话每轮只聚焦一个主要缺口，不考材料未提供的机制，也不为了流程制造问题。你说“懂了”不被当作独立解释证据。

你仍可随时要求直接讲解、画图或归档；需要且有依据的重讲未进行时标记待重讲；依据不足的问题单独记录，照常保存。图和总结区分你的表达、AI 示范与待验证关系。复习与实验可选，不增加强制闯关。

## 文件

- [学习索引](LEARNING-INDEX.md)：已归档主题、来源、学习状态和待核实问题。
- `AGENTS.md`：仓库协作和记录规则。
- `.agents/skills/`：三个独立 Skill。
- `templates/`：可选笔记模板，按需裁剪。
- `inbox/`：待整理输入。
- `topics/<主题>/`：来源、会话、当前总结和学习状态。
- `reviews/queue.md`：待复测主题。

简单问题可以只保存一个文件。首次创建主题时采用简短、稳定的目录名，避免重复主题。

## 记录与同步

记录原始解释、验证依据和待解决问题；不把 AI 补充当作你的掌握证据。只看过材料记为“已接触”，能独立解释记为“能解释”，有新情境验证记为“能应用”，有延迟验证才记为“复测通过”。状态适用于具体知识点，允许回退。

“归档”表示写入本地文件；“提交”表示 Git commit；“同步到 GitHub”表示 push。未另行约定时不自动提交、推送或创建远程仓库。仓库已经发布 v0.1 内容；本地安装与远程同步分别进行，新改动不自动发布，也不保证其他 Codex 环境已安装。

复测由你发起，或在恢复主题时提示到期条目；本项目没有后台定时任务。复习时间由你指定；未指定时只记录待安排。

原文和视频默认保存链接、必要摘录及时间点。无法读取的内容明确标注，不虚构正文、字幕或出处。学习记录可能包含个人内容；发布前选择合适的仓库可见性。
